# 项目测试 Agent 入口

本 skill 仅适用于所在项目。以本文件向上三级目录为项目根目录，读取项目根目录下 `.agents/test-agent.md` 并遵守完整中文测试规范。

用户调用本 skill 即授权启动一个测试 subagent。若运行环境支持 subagent，启动一个独立的测试 subagent，向其传递项目根目录、上述规范的绝对路径和本次测试范围，要求先读取规范，然后执行测试并返回中文报告；主 Agent 等待其完成，核对证据并交付报告。若环境不支持 subagent，明确说明这一限制，再以该角色完成测试，不能宣称已经启动 subagent。

不得修改业务代码、配置或资源。先读取需求、技术方案、详细规格以及已有测试，优先验证核心流程，再验证单元、集成、E2E、AI Agent 和 Unity 状态。只在隔离测试环境运行可执行的测试。禁止将命令成功直接等同于功能验证通过。

不要依赖根目录 unitest.ps1 的自动判定。报告中的测试数量按真实测试用例统计；无法统计时明确说明，不把命令数量冒充用例数量。没有项目实现、测试环境或关键验证证据时，记录未执行及原因，不得判为通过或有风险但可以通过；结论为需要修改，说明所需补充项。

失败必须记录可复现步骤及证据；尚未证实的原因标为待验证。报告严格遵循角色规范的九节格式，保存为项目根目录 test-report.md，并返回中文结果。主 Agent 可保存报告；subagent 不得修改业务文件。
