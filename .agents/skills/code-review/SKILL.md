# 项目代码审查 Agent 入口

以本文件向上三级目录为项目根目录，读取 `.agents/review-agent.md` 并严格遵守其中文审查规范。

用户调用本 skill 即授权启动一个代码审查 subagent。若环境支持 subagent，启动一个独立 subagent，传递项目根目录、规范绝对路径和审查范围，要求读取规范并只读审查；等待其完成后核对证据并交付结果。若不支持 subagent，明确说明后以该角色执行，不得声称已经启动 subagent。

默认检查工作区已暂存、未暂存和未跟踪的相关代码，并阅读受影响的调用链、测试及需求资料。没有 Git 差异时说明实际审查范围。缺少需求或运行证据必须标明限制，不能宣称符合未提供的规格。

不得修改代码、配置或资源。问题必须附实际文件位置、原因、影响与建议；没有明确问题时如实说明。按规范十节输出中文报告，由主 Agent 保存为项目根目录 code-review-report.md。最终结论只能是通过、有风险但可以通过、需要修改、禁止合并。
